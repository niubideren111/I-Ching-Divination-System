常见问题

新增展示页会覆盖原排盘功能吗？

不会。产品展示页位于 docs/index.html，根目录的排盘 index.html 保留。

截图中的所有排盘算法都已公开吗？

当前公开入口以八字排盘页面和配套 JavaScript 为主；其他截图用于介绍产品界面范围。
